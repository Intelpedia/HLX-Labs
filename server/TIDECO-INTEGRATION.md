# Cleffo to TideCo fulfillment

New payment processing uses the Supabase `cleffo-payments` function.
See [CLEFFO-INTEGRATION.md](CLEFFO-INTEGRATION.md) for the current integration status, payment verification, and supplier tests.

The `tideco-order-intake` relay and tracking callback continue to serve the supplier connection. TagadaPay payment ingestion is retired.
